# اپلیکیشن اندروید ضایعات خشک

این پروژه نسخه اندرویدی سایت رسمی ضایعات خشک است و در این نسخه، رابط وب فعلی داخل یک پوسته Android WebView اجرا می‌شود تا سایت و اپلیکیشن از همان اطلاعات و سرویس Supabase استفاده کنند.

## امکانات
- نمایش سایت زنده ضایعات خشک
- پشتیبانی از ورود و نشست مدیران
- انتخاب و آپلود فایل از حافظه گوشی
- اجازه دسترسی مکانی برای انتخاب موقعیت روی نقشه
- پشتیبانی از لینک‌های تماس تلفنی
- دکمه بازگشت اندروید برای جابه‌جایی بین صفحات

## ساخت APK
با هر Push به شاخه اصلی که فایل‌های `android-app/**` را تغییر دهد، GitHub Actions نسخه Debug را می‌سازد. همچنین می‌توان از تب Actions گردش‌کار **Build Zayeat Android APK** را دستی اجرا کرد.

پس از موفقیت Build، در بخش Artifacts فایل `Zayeat-Android-debug` را دریافت کنید. فایل نصب داخل آن `app-debug.apk` است.

## مشخصات
- Application ID: `com.zayeat.app`
- حداقل اندروید: Android 6.0 (API 23)
- نسخه اولیه: 1.0.0

> این نسخه به اینترنت نیاز دارد. اطلاعات کاربران، محصولات و فایل‌ها از همان وب‌سایت و پروژه Supabase خوانده می‌شوند؛ این برنامه دیتابیس جداگانه‌ای ایجاد نمی‌کند.
